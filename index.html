How to Play

YOUR MISSION IS TO CAPITALIZE AND PUNCTUATE THE FOLLOWING PUZZLE CORRECTLY.

  • To Punctuate: Place the cursor where the mark belongs, then select the correct symbol from the bottom row.
  • To Capitalize: Place the cursor to the left of the letter you want to capitalize, then click the "C" button.
  • Watch Out: Errors will not be accepted. An alert will let you know if you chose incorrectly.
  • Need Help? Click the Hint button to see exactly how many of each type of punctuation mark is required and how many words need to be capitalized.
  • Want to Quit Early?
    • Click Return Home to start a new puzzle.
    • Click the Show Solution button to stop the clock and see the solution.
    • Click the Word Type button to proceed to the Word Type Identification Puzzle.

THE TIMER WILL STOP AUTOMATICALLY ONCE THE PUZZLE IS COMPLETED.
